Materi networking untuk persiapan technical interview. Penjelasannya dibuat sederhana, dengan contoh jawaban Indonesia dan English yang natural, supaya lu lebih gampang paham dan menjelaskan konsepnya saat interview.

"A simple networking guide for technical interviews. The explanations are practical, easy to understand, and easy to explain."

Executive Summary

Kesimpulan & Insight Materi

OSI & Troubleshooting

Jaringan komputer beroperasi secara berlapis. Troubleshooting selalu dimulai secara terstruktur (Bottom-Up) dari layer terbawah (Fisik/Kabel) sebelum melompat menyalahkan konfigurasi software atau IP.

VLAN & Routing

VLAN memecah jaringan secara logis agar aman dan bebas dari broadcast storm. Sementara Routing Protocol bertindak sebagai GPS cerdas yang memastikan data antar VLAN bisa saling menemukan jalan tercepat.

Fiber Optic (GPON)

Arsitektur GPON membuktikan bahwa bandwidth raksasa bisa didistribusikan ke ribuan rumah pelanggan secara pasif (tanpa butuh aliran listrik di jalanan), memangkas cost operasional besar-besaran.

Linux CLI

Menguasai terminal Linux bukan sekadar gaya. Ini adalah kemampuan mutlak untuk memantau performa *server* secara *real-time* dan menemukan akar penyebab masalah (*root cause*) lewat pembacaan log.

Excel Reporting

Data mentah berjumlah ribuan baris dari NMS tidak ada nilainya tanpa pengolahan. Penguasaan VLOOKUP dan PivotTable adalah jembatan untuk mengubah data teknis menjadi laporan metrik performa (*SLA*).

Culture Fit (HR)

Di dunia jaringan operasional 24/7, hard skill akan mendatangkan panggilan *interview*, tetapi ketenangan saat menghadapi downtime dan kemampuan menjalin komunikasi yang menentukan lu diterima kerja.

01 — The Blueprint

OSI Layer (Dari Application Sampai Physical)

"The OSI model is a reference model with seven layers. It helps explain how data communication works from one device to another."

7

Application

Layanan yang Dipakai Aplikasi
+

Layer 7 atau Application Layer berhubungan dengan layanan jaringan yang digunakan oleh aplikasi, seperti web browsing, email, dan DNS.

"Layer 7, or the Application Layer, is where applications use network services, such as web browsing, email, and DNS."

HTTP/HTTPSDNSSMTP
6

Presentation

Format dan Penyajian Data
+

Layer 6 atau Presentation Layer berhubungan dengan format data, termasuk encoding, encryption, dan compression.

"Layer 6 handles how data is formatted, encoded, encrypted, or compressed."

SSL/TLSJPEG / MP4Data Compression
5

Session

Mengatur Sesi Komunikasi
+

Layer 5 atau Session Layer mengatur sesi komunikasi antara dua perangkat, termasuk membuka, menjaga, dan menutup sesi.

"Layer 5 manages the communication session between two devices, including starting, maintaining, and ending the session."

Session IDNetBIOS
4

Transport

Pengiriman Data (TCP vs UDP)
+

Layer 4 atau Transport Layer bertanggung jawab untuk pengiriman data dari satu perangkat ke perangkat lain. Di sini kita mengenal TCP dan UDP. TCP lebih mengutamakan keandalan, sedangkan UDP lebih mengutamakan kecepatan. Port number juga digunakan di layer ini.

"Layer 4, or the Transport Layer, is responsible for delivering data between devices. TCP focuses more on reliability, while UDP focuses more on speed. Port numbers are also used at this layer."

TCPUDPPort Numbers
3

Network

IP Address dan Routing
+

Layer 3 atau Network Layer berhubungan dengan IP Address dan routing. Layer ini membantu paket data menuju jaringan tujuan.

"Layer 3 uses IP addressing and routing to move packets between different networks."

IP Address (IPv4/IPv6)RouterOSPF / BGP
2

Data Link

Komunikasi Lokal (MAC, Switch, VLAN)
+

Layer 2 atau Data Link Layer berfungsi untuk komunikasi dalam satu jaringan lokal. Di layer ini kita mengenal MAC Address, Frame, Switch, dan VLAN.

"Layer 2, or the Data Link Layer, is responsible for communication within a local network. It uses MAC addresses, and we also have frames, switches, and VLANs at this layer."

MAC AddressSwitchVLAN (802.1Q)
1

Physical

Media Fisik
+

Layer 1 atau Physical Layer berhubungan dengan media fisik untuk mengirim data, seperti kabel, sinyal, dan konektor seperti RJ45.

"Layer 1, or the Physical Layer, is about the physical media used to transmit data, such as cables, signals, and connectors like RJ45."

UTP CableFiber OpticBinary Bits

Interview Flashcards - OSI Layer

Apa fungsi OSI Layer?+
"The OSI model is a reference model with seven layers. It helps explain how data communication works from one device to another."

Versi Indonesia: OSI adalah model referensi dengan tujuh layer untuk menjelaskan bagaimana komunikasi data terjadi dari satu perangkat ke perangkat lain.

Sebutkan Layer 1 sampai 7 secara berurutan.+
"From bottom to top: Physical, Data Link, Network, Transport, Session, Presentation, and Application."

Versi Indonesia: Physical, Data Link, Network, Transport, Session, Presentation, dan Application.

Layer 2 dan Layer 3 bedanya apa?+
"Layer 2 handles Frames using MAC addresses for local switching, while Layer 3 handles Packets using IP addresses for routing between different networks."

Versi Indonesia: Layer 2 menangani *Frame* menggunakan MAC Address (Switching, VLAN untuk memecah broadcast domain). Layer 3 menangani *Packet* menggunakan IP Address (Routing untuk menghubungkan network yang berbeda).

Apa beda TCP dan UDP? (Layer 4)+
"TCP is reliable because it uses Sequence Numbers, Acknowledgement, and Retransmission to ensure data integrity, starting with a 3-way handshake. UDP is connectionless and prioritizes speed."

Versi Indonesia: TCP reliable bukan cuma karena 3-way handshake (ini untuk establish connection), melainkan karena adanya Sequence Number, Acknowledgement, dan Retransmission untuk memastikan data utuh. Sedangkan UDP lebih mengutamakan kecepatan (cocok untuk streaming/video call).

Kalau ada kabel FO (Fiber Optic) putus atau redaman loss, itu masuk trouble di layer berapa?+
"A fiber cut or LOS issue falls under Layer 1, the Physical Layer, because it deals with the physical medium and light signals."

Versi Indonesia: Masuk ke Layer 1 (Physical), karena ini murni masalah pada media fisiknya atau transmisi sinyal cahayanya.

Interview Flashcards - TCP/IP & Ports

Apa perbedaan mendasar OSI dan TCP/IP?+
"OSI has seven layers and is mainly used as a reference model for learning and troubleshooting. TCP/IP has four layers and is the practical model commonly used in real networks."

Versi Indonesia: OSI itu framework teoritis dengan 7 layer, sedangkan TCP/IP itu yang benar-benar dipakai di internet nyata dengan 4 layer.

Port number bekerja di layer berapa pada OSI?+
"Port numbers operate at Layer 4, the Transport Layer."

Versi Indonesia: Port number (seperti 80, 443) digunakan pada Layer 4 (Transport Layer).

DNS menggunakan TCP atau UDP di port berapa?+
"No. DNS commonly uses UDP port 53 for regular queries, but it can use TCP port 53 for cases such as zone transfers, responses requiring TCP fallback, and modern protocols like DNS over TLS/HTTPS."

Versi Indonesia: Port 53. Umumnya pakai UDP 53 untuk query biasa agar cepat. TCP 53 dipakai untuk zone transfer, payload yang terlalu besar, fallback, atau teknologi modern seperti DNS over TLS/HTTPS.

03 — How to Fix Things

Basic Troubleshooting — Cara Menjawab Saat Interview

"A common interview question: if a user cannot access the internet, explain how you would check the problem step by step using the OSI model."

SKENARIO
HR: "Kalau ada komputer yang tidak bisa konek internet, mulai cek dari mana?"

Jawab secara terstruktur. Walaupun metode Bottom-Up (dari fisik/kabel naik ke atas) sangat direkomendasikan, di dunia nyata kita juga bisa pakai Top-Down atau Divide & Conquer tergantung gejala error.

1. Layer 1 (Physical) - Cek Fisik "Pertama, pastikan koneksi fisiknya normal. Cek kabel LAN dan link light. Kalau menggunakan WiFi, cek koneksi ke SSID yang benar."

"First, I would check Layer 1 by checking the physical connection, the LAN cable, and the link lights."

2. Layer 2 (Data Link) - Cek Switch & VLAN "Then, I would check Layer 2. I would make sure the switch port is active and assigned to the correct VLAN."

"Next, I would check Layer 2 and make sure the switch port is active and assigned to the correct VLAN."

3. Layer 3 (Network) - Cek IP & Ping "Next, check whether the PC has the correct IP Address. I can also ping an external IP such as 8.8.8.8 to check connectivity."

"At Layer 3, I would check the IP configuration and ping an external IP such as 8.8.8.8. If it fails, I would check the default gateway and routing."

4. Layer 7 (Application) - Cek DNS "If pinging an IP works but a website does not open, I would check DNS. I can use nslookup to check whether the domain name is resolved correctly."

"If an IP can be reached but a website cannot be opened, I would check the DNS resolution."

04 — Local Isolation

VLAN (Virtual LAN) & Switching

"VLANs allow one physical switch to separate devices into different logical networks. This helps separate traffic and control broadcast domains."

VLAN digunakan untuk memisahkan jaringan secara logical. Beberapa VLAN bisa dibuat pada satu switch fisik, sehingga perangkat dalam VLAN yang berbeda tetap terpisah pada Layer 2.

"With VLANs, traffic can be separated at Layer 2. Devices in different VLANs need Layer 3 routing to communicate with each other."

Dua istilah port switch yang penting:

  • Access Port: Port yang biasanya digunakan untuk perangkat user dan membawa satu VLAN.
  • Trunk Port: Port yang membawa beberapa VLAN dan biasanya digunakan untuk koneksi antar-switch atau ke perangkat Layer 3.
Ilustrasi Pemisahan Logis di 1 Hardware

Interview Flashcards - VLAN

Apa itu VLAN dan fungsinya?+
"VLAN is used to separate a physical network into different logical networks, to improve security and reduce broadcast domains."

Versi Indonesia: VLAN digunakan untuk memisahkan satu jaringan fisik (satu Switch) menjadi beberapa jaringan logis yang berbeda untuk alasan keamanan dan kerapian.

Beda Access Port dan Trunk Port?+
"An access port normally carries one VLAN for an end device (like a PC), while a trunk port carries multiple VLANs, usually connected between switches or to a router."

Versi Indonesia: Access port itu buat colok ke komputer (bawa 1 VLAN aja), kalau Trunk port itu jalur bebas hambatan buat nyambungin Switch ke Switch (bawa banyak VLAN sekaligus).

Bisa gak perangkat di VLAN A langsung komunikasi ke VLAN B tanpa Router?+
"No. Devices in different VLANs are essentially in different networks. They need Layer 3 routing, such as Inter-VLAN routing or a Layer 3 Switch, to communicate."

Versi Indonesia: Nggak bisa. Karena mereka sudah beda segmen jaringan (meski 1 hardware). Wajib pakai proses Routing (bantuan Router atau Switch Layer 3).

Static Route vs Dynamic Route

Sebelum masuk ke jenis-jenis protokol (RIP, OSPF, BGP), pahami dulu dua kategori utama dalam mengatur jalan untuk data.

1. Static Route

Dikonfigurasi manual oleh admin. Ibarat mengetik rute jalan di GPS secara manual belokan per belokan.
Jika jalanan ditutup (kabel putus), data akan mandek karena router tidak tahu jalan alternatif.
Sangat ringan, tidak membebani memori CPU router karena tidak perlu menghitung rute.

2. Dynamic Route

Dikonfigurasi otomatis via protokol. Ibarat pakai *Google Maps*, router saling melapor kondisi jalan ter-update.
Jika kabel putus, router cerdas mencari jalan memutar dengan sendirinya (Auto-Failover).
Membutuhkan RAM & CPU ekstra untuk kalkulasi jalan terbaik.
PROTOL DYNAMIC ROUTING:

Static Route (Rute Manual)

Static Route adalah rute yang dikonfigurasi secara manual pada router. Rute ini sederhana dan sering digunakan pada jaringan kecil atau sebagai Default Route menuju gateway atau ISP.

"A static route is configured manually on the router. It is simple and predictable, but it does not automatically adapt when the network changes."

Kategori
Manual Input
Kelebihan
Ringan untuk CPU Router
Kapan Dipakai?
Jaringan kecil atau rute utama ke ISP

RIPv2 (Routing Information Protocol)

RIP adalah protokol lawas berbasis Distance-Vector. Dia menentukan jalur terbaik semata-mata berdasarkan jumlah lompatan router (Hop Count) dengan batas maksimal 15 lompatan. Kurang disarankan untuk jaringan modern.

"A legacy Distance-Vector protocol. It relies solely on hop count to determine the best path, with a maximum limit of 15 hops. Not ideal for complex or large-scale modern networks."

Tipe
Dynamic (Distance Vector)
Parameter Jalan
Hop Count (Maks 15)
Kapan Dipakai?
Jaringan sangat kecil/jadul

EIGRP (Enhanced Interior Gateway Routing Protocol)

EIGRP awalnya adalah protokol proprietary buatan Cisco (sekarang sudah terbuka sebagian). Dikenal sebagai Advanced Distance Vector atau Hybrid karena menggabungkan fitur terbaik dari Link-State dan Distance Vector. Metriknya sangat presisi meliputi Bandwidth, Delay, Load, dan Reliability.

"An advanced distance-vector routing protocol originally proprietary to Cisco. It offers extremely fast convergence using the DUAL algorithm and calculates routes based on a complex metric of bandwidth and delay."

Tipe
Dynamic (Hybrid)
Parameter Jalan
Bandwidth & Delay
Kecepatan Adaptasi
Sangat Cepat (DUAL Algorithm)

OSPF (Open Shortest Path First)

OSPF adalah routing protocol berbasis Link-State. Router saling bertukar informasi topologi dan menggunakan nilai Cost untuk menentukan jalur terbaik. OSPF umum digunakan untuk routing internal.

"OSPF is a Link-State routing protocol. Routers exchange topology information and use cost to select the best path. It is commonly used for internal routing."

Tipe
Dynamic (Link-State)
Parameter Jalan
Bandwidth / Cost
Kecepatan Adaptasi
Sangat Cepat (Fast Convergence)

BGP (Border Gateway Protocol)

BGP digunakan untuk bertukar informasi routing antara Autonomous System yang berbeda. BGP banyak digunakan antara ISP dan jaringan besar, dan keputusan routing dapat dipengaruhi oleh policy dan path attributes.

"BGP is used to exchange routing information between different Autonomous Systems. It is commonly used between ISPs and large networks, where routing decisions can be influenced by policies and path attributes."

Tipe
Dynamic (Path Vector/EGP)
Parameter Jalan
Policy (AS-Path, Local Pref)
Kapan Dipakai?
Peering Internet antar ISP

Konsep Lanjutan: Backup Link & OSPF Cost

Di industri nyata, engineer merancang routing agar saat satu kabel putus, koneksi otomatis pindah ke jalur cadangan tanpa downtime parah.

Topologi 1: Static Route (Floating Backup)

Router selalu memilih jalur dengan AD (Administrative Distance) terkecil (Fiber). Jika kabel Fiber putus, rute jalur Radio (AD 10) akan otomatis menggantikan di tabel routing.

Topologi 2: Dynamic Route (OSPF Auto-Path)

OSPF mencari rute dengan total Cost terendah secara akumulatif berdasarkan bandwidth. Bukan sekadar jarak fisik terpendek. Makanya data muter lewat atas.

Interview Flashcards - Routing Protocol

Apa perbedaan mendasar antara Static Route dan Dynamic Route?+
"Static routing is manually configured by a network administrator, while dynamic routing uses protocols (like OSPF or BGP) to automatically learn and update routing tables."

Versi Indonesia: Static route diisi manual satu-satu oleh admin. Kalau Dynamic route, router-router saling lapor status jaringan dan otomatis nyusun rute terbaiknya sendiri.

Kapan saat yang tepat menggunakan Static Route vs Dynamic Route?+
"Static routing is best for small, simple networks or for creating a default route to an ISP, because it consumes less CPU. Dynamic routing is better for large networks where paths can change frequently."

Versi Indonesia: Static enak buat jaringan kecil atau numpang jalan ke ISP karena nggak ngabisin CPU router. Kalau routernya banyak dan butuh jalur pindah otomatis kalau kabel putus, wajib pakai Dynamic.

Apa beda IGP dan EGP?+
"IGP (Interior Gateway Protocol) is used for routing within a single Autonomous System (AS), like OSPF or EIGRP. EGP (Exterior Gateway Protocol) is used for routing between different Autonomous Systems, like BGP."

Versi Indonesia: IGP buat jaringan internal dalam 1 perusahaan/organisasi. EGP buat komunikasi eksternal beda perusahaan, misalnya peering antar ISP.

Bagaimana cara OSPF memilih jalur memutar dibanding jalur lurus yang lambat?+
"Because OSPF selects the path with the lowest cumulative cost, not necessarily the physically shortest path. Cost is based on interface bandwidth."

Versi Indonesia: Karena OSPF mencari rute dengan total *Cost* terendah secara akumulatif berdasarkan *bandwidth*. Bukan sekadar memprioritaskan jarak fisik terpendek/lurus.

Apa itu Administrative Distance (AD)?+
"Administrative Distance is the 'trustworthiness' of a routing protocol. The lower the AD value, the more trusted the route is. For example, a Directly Connected route has an AD of 0, Static Route has 1, and OSPF has 110."

Versi Indonesia: AD itu tingkat prioritas kepercayaan router terhadap suatu jalur. Makin kecil angkanya, makin dipilih duluan. Makanya router lebih milih jalur Static (AD 1) dibanding jalur OSPF (AD 110) kalau tujuannya sama.

Bagaimana cara membuat jalur backup otomatis menggunakan Static Route?+
"We can create a Floating Static Route by assigning an Administrative Distance (AD) that is higher than the primary route. If the primary route fails, the backup route with the higher AD will be injected into the routing table."

Versi Indonesia: Bikin dua rute ke tujuan yang sama. Rute utama (misal Kabel Fiber) dibikin biasa (AD 1). Rute cadangan (misal Radio) kita setting angka AD-nya jadi 10. Pas kabel fiber putus, router otomatis pindah ke jalur radio karena AD 1 hilang.

SQL & Database Basics

"SQL is the standard language for relational database management systems. It's a must-have skill for a Data Analyst."

Sebagai Data Analyst atau Engineer, lu bakal sering dihadapkan dengan database langsung. Menguasai SQL dasar adalah kewajiban mutlak buat narik data mentah (querying).

-- Menampilkan semua kolom dari tabel pelanggan
SELECT * FROM pelanggan;

-- Filter data menggunakan WHERE
SELECT nama, area FROM pelanggan
WHERE status = 'Aktif';

-- Mengurutkan data (ORDER BY) dari yang terbesar ke terkecil
SELECT nama, tagihan FROM pelanggan
ORDER BY tagihan DESC;
-- Merekap total order per STO (Central Office)
SELECT 
    sto, 
    COUNT(*) AS total_order 
FROM orders 
GROUP BY sto;

-- Menghitung total pendapatan (SUM) dan Rata-rata (AVG)
SELECT 
    area, 
    SUM(tagihan) AS total_pendapatan,
    AVG(tagihan) AS rata_rata
FROM billing
GROUP BY area;

-- Menghitung jumlah pelanggan UNIK (Tidak ada duplikat)
SELECT COUNT(DISTINCT id_pelanggan) FROM orders;
-- HAVING digunakan untuk memfilter hasil dari GROUP BY
SELECT sto, COUNT(*) AS total_order 
FROM orders 
GROUP BY sto 
HAVING COUNT(*) > 100;

-- CASE WHEN: Membuat logika If-Else di SQL
SELECT nama, 
    CASE 
        WHEN tagihan > 500000 THEN 'Premium'
        ELSE 'Regular' 
    END AS tipe_pelanggan
FROM pelanggan;

-- Menampilkan data yang kolom email-nya kosong (NULL)
SELECT * FROM pelanggan WHERE email IS NULL;
-- PRIMARY KEY: ID Unik di sebuah tabel (Misal: id_pelanggan)
-- FOREIGN KEY: ID dari tabel lain yang dipakai sebagai penghubung

-- INNER JOIN: Menggabungkan data dari 2 tabel yang saling berhubungan
SELECT 
    pelanggan.nama, 
    layanan.jenis_paket 
FROM pelanggan
INNER JOIN layanan 
    ON pelanggan.id_layanan = layanan.id_layanan;

Interview Flashcards - SQL

What is the difference between WHERE and HAVING?+
"WHERE is used to filter records before any groupings are made, while HAVING is used to filter values after they have been grouped using aggregate functions."

Versi Indonesia: Secara gampang, WHERE dipakai untuk memfilter baris data asli *sebelum* di-grouping (nggak bisa pakai fungsi aggregasi kayak SUM/COUNT). Kalau HAVING dipakai untuk memfilter hasil *setelah* di-grouping (bisa memfilter hasil dari SUM/COUNT).

Jelaskan bedanya Primary Key dan Foreign Key.+
"A Primary Key uniquely identifies a record in a table. A Foreign Key is a field in one table that uniquely identifies a row of another table, linking the two tables together."

Versi Indonesia: Primary Key itu nomor identitas unik di tabel dia sendiri (misal NIK KTP). Foreign Key itu Primary Key dari tabel lain yang numpang di tabel ini biar kedua tabelnya bisa nyambung (JOIN).

Apa fungsi COUNT DISTINCT?+
"COUNT DISTINCT counts only the unique values in a column, ignoring duplicates."

Versi Indonesia: Beda sama COUNT biasa yang ngitung semua baris. COUNT DISTINCT cuma ngitung nilai yang unik (nggak dobel). Jadi kalau ada 1 pelanggan order 5 kali, di COUNT biasa dihitung 5, di COUNT DISTINCT cuma dihitung 1.

Kenapa Anda ingin resign / pindah dari perusahaan sebelumnya?+
Selalu jawab positif, jangan pernah menjelekkan tempat kerja lama. Arahkan ke motif "growth", bukan "lari dari masalah".

"I'm not leaving because of a bad experience, but because I'm looking for a bigger challenge and an opportunity to grow — especially to work directly with more advanced network technology and expand my skill set."
Berapa ekspektasi gaji Anda?+
Kasih range berdasarkan riset (glassdoor/gaji sejenis di industri), jangan langsung angka mati, dan tunjukkan fleksibilitas.

"Based on my research for this role and my experience, I'm expecting a range of [sebutkan angka], but I'm open to discussing further based on the full benefits package and scope of responsibility."
Apakah Anda bersedia bekerja shift, on-call, atau lembur jika terjadi gangguan mendadak?+
Untuk posisi NOC/Network Engineer/IT Ops, kesediaan shift & standby itu wajib — tunjukkan lu paham konsekuensi kerjaan operasional 24/7.

"Yes, I understand technical operations require 24/7 availability. I'm used to shift work and being on standby for critical incidents, since customer connectivity issues can't wait until the next business day."
Di mana Anda melihat diri Anda dalam 5 tahun ke depan?+
Jawaban fleksibel (Bisa dipakai buat lamar Analis / Data / Jaringan):

"In the next five years, I want to grow into a more senior technical role where I can combine my operational experience with data analysis, automation, and technology. I’m also open to developing deeper expertise based on the needs of the role and the company."

Dibuat untuk Technical Interview. Good luck!
